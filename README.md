# Спорт Мордовии — интерактивная Telegram-демоверсия

Это **HTML-макет**, воспроизводящий текущую тестовую версию Telegram-бота «Спорт Мордовии» (11 ноября 2026 года).

**[Открыть демонстрацию](https://vzloman546-design.github.io/demo-bot/)**

### Что воспроизведено
- Все 42 информационных экрана и 98 кнопок из `content/pages.json` Telegram-проекта.
- Оформление чата в стиле Telegram, адаптация для телефонов и компьютеров.
- Главное меню: расположение кнопок 2+2+2+1.
- Первый уровень: одна кнопка «⌂ Главное меню»; вложенные уровни: «← Назад» и «⌂ Меню».
- Переходы в том же сообщении, работа команд `/start`, `/menu`, `/reset`, `/help`, выбор раздела по тексту, внешние HTTPS-ссылки.
- Переключение светлой и тёмной темы.

### Технически
`index.html` — автономный документ, запускается даже локально без сервера. Данные страниц **встроены в HTML** и взяты из `content/pages.json` Telegram-проекта; сам Python-бот, токен и база SQLite сюда не публикуются.

Это не подключение к Telegram API, а демонстрация пользовательского интерфейса. Афиша и некоторые справочные сведения демонстрационные; перед официальным использованием необходима проверка министерством.

Если GitHub Pages ещё не активирован: Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
